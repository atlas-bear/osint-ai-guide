# Security

This repository contains documentation only. It runs no code and holds no user data.

If you find something in the guide that could put a reader at risk, for example advice that leaks an investigator's identity or a tool with an undisclosed data flow, please tell us privately first so we can fix it before it is discussed in public.

- Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"), or
- Email [support@atlasbear.co](mailto:support@atlasbear.co).

We aim to acknowledge reports within five working days. Please do not include any personal data about third parties in a report.
